# QC factcard reference (public excerpt)

External claims vocabulary rules enforced by qc-gate out-side checks:

- License layers: verifier=MIT checker; CC0 covers vector data only; PyPI verifier packages are ELv2.
- No pricing figures in public claims (prices are owner-approved per engagement only).
- No CVE counts in public claims.
- Performance figures must carry their test scope (in-process kernel vs full fail-closed cross-process).
- Cold outreach requires owner approval + address verification + ledger entry.
